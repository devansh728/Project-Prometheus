# EV Cooling System: Thermal Management

## Overview

EVs have multiple cooling loops:

1. **Battery Thermal Management** - Most critical
2. **Motor/Inverter Cooling**
3. **Cabin HVAC**

Proper thermal management extends battery life and prevents performance throttling.

## Common Issues

### Coolant Level Low

**Symptoms:** Temperature warnings, reduced performance, battery throttling.
**Causes:**

- Slow leak in hoses or radiator
- Expansion tank crack
- Head gasket degradation (rare in EVs)

**Diagnosis Steps:**

1. Pressure test cooling system (15 psi, 10 min)
2. Visual inspection of all hoses and connections
3. UV dye test for slow leaks
4. Check expansion tank for cracks

**Recommended Action:**

- Top up with OEM-specified coolant
- Replace leaking components
- Flush system if contaminated

---

### Overheating During Fast Charging

**Symptoms:** Charging speed throttled, temperature warnings during DC fast charge.
**Causes:**

- Coolant pump failure
- Clogged radiator fins
- Ambient temperature > 35°C

**Diagnosis Steps:**

1. Verify coolant pump operation (listen/feel)
2. Check radiator airflow (clean debris)
3. Review battery temperature logs during charging

**Recommended Action:**

- Coolant pump replacement if faulty
- Radiator cleaning or replacement
- Recommend charging in cooler conditions

## Preventive Maintenance Schedule

| Interval   | Action                         |
| ---------- | ------------------------------ |
| 20,000 km  | Visual inspection, level check |
| 60,000 km  | Coolant flush and refill       |
| 100,000 km | Replace thermostat, hoses      |

## DTC Reference

- **P0128**: Coolant Thermostat (Below Regulating Temperature)
- **P0116**: Engine Coolant Temperature Sensor Range/Performance
- **P0118**: Engine Coolant Temperature Sensor High Input
